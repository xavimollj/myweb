1. Vision del proyecto

Gastrodigital Hub es la marca personal de Xavi, consultor de marketing local especializado en restauracion y gastronomia en Barcelona. La web sirve para captar clientes (restaurantes y bares) y presentar tres herramientas SaaS que el cliente podra activar desde su propio panel.

Objetivo del consultor: escalar de 4 a 8 clientes activos en 6 meses, y a 5.000€/mes en 12 meses.

Posicionamiento: especialista en SEO local + gestion automatizada para restauracion. Tono profesional pero cercano, sin tecnicismos.

3. Tres propuestas de valor

Diferenciadores frente a la competencia. Cada cliente podra activarlos desde su panel privado.

Herramienta 01 · App de Menu con IA + Club VIP teal

El restaurante hace una foto al plato. La IA detecta automaticamente el nombre, redacta una descripcion apetecible y actualiza la web en segundos. Sin codigo.

Club VIP gratuito: los clientes finales reciben el menu del dia por WhatsApp, Telegram o email. Fidelizacion sin esfuerzo.

Herramienta 02 · Sistema de Resenas 360° coral

No solo respuestas: captacion etica con QR + tarjetas NFC + CRM interno. Las resenas llegan solas y se gestionan solas. Respuestas automaticas con el tono de cada restaurante. 100% dentro de las politicas de Google.

Herramienta 03 · Gestion Inteligente de Reservas teal

Recordatorios automaticos al cliente dias antes, dia anterior y horas antes de la reserva. Aviso al restaurante en tiempo real. Lista de espera automatica para aprovechar cancelaciones. Reduce drasticamente los no-shows.

4. Estructura de la web

Single-page landing en index.html, bilingue ES/CA con toggle de idioma.

  1. Nav fija — logo + links + toggle ES/CA + CTA
  2. Hero — titular grande con foto de restaurante de fondo + panel con las 3 herramientas
  3. Problemas — 4 cards con los dolores tipicos del restaurador
  4. Herramientas — los 3 bloques con imagen IA y bullets
  5. Proceso — 4 pasos: consulta, auditoria, activacion, seguimiento
  6. Sobre mi — presentacion de Xavi + stats
  7. CTA final — WhatsApp + email
  8. Footer — contacto + redes

5. Tecnologia utilizada

  • HTML5 + CSS3 puro (sin frameworks)
  • JavaScript vanilla para toggle de idioma y scroll reveal
  • Google Fonts — Montserrat (CDN)
  • OpenAI API (gpt-image-1) para generacion de imagenes
  • Git + GitHub como repositorio
  • Vercel para despliegue automatico

Por que sin frameworks: el sitio es estatico, no necesita build step, carga rapido y es facil de mantener. Una sola persona puede editarlo abriendo el archivo HTML.

6. Generacion de imagenes con IA

Las 4 imagenes principales fueron generadas con gpt-image-1 de OpenAI:

  • img/hero.png — restaurante oscuro con luz ambar (1536x1024)
  • img/tool-menu.png — chef con plato y movil con overlay IA
  • img/tool-reviews.png — QR + NFC + estrellas en tablet
  • img/tool-reservations.png — tablet con calendario teal

Llamada a la API (ejemplo)

POST https://api.openai.com/v1/images/generations
Headers: Authorization: Bearer $OPENAI_API_KEY
Body: {
  "model": "gpt-image-1",
  "prompt": "...",
  "n": 1,
  "size": "1024x1024",
  "quality": "high"
}

La clave esta en .env y excluida del repositorio (via .gitignore). Nunca llega a GitHub.

7. Despliegue

Flujo en dos pasos:

  1. GitHub — el codigo vive en github.com/xavimollj/myweb (rama main). Cada cambio se hace commit y push.
  2. Vercel — conectado al repo de GitHub. Cada push a main dispara un deploy automatico a produccion. URL publica una vez configurado el dominio.

Para actualizar la web

git add .
git commit -m "tu mensaje"
git push origin main
# Vercel despliega solo
